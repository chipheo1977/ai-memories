# bugs/

Bug KHÓ đã tốn nhiều thời gian điều tra. Không ghi bug thường (fix xong là xong).

Cấu trúc nội dung: **Triệu chứng** (biểu hiện, thông báo lỗi nguyên văn để grep được) →
**Nguyên nhân gốc** → **Cách phát hiện lần sau** (dấu hiệu nhận biết sớm, lệnh chẩn đoán) →
**Cách fix / workaround**.

Tiêu chí: bug có khả năng tái xuất hiện (ở project khác, hoặc dạng khác) và nguyên nhân
không hiển nhiên từ triệu chứng.
