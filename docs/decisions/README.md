# decisions/

Quyết định kỹ thuật kèm LÝ DO — dạng ADR ngắn.

Cấu trúc nội dung: **Bối cảnh** (vấn đề gì, ràng buộc gì) → **Quyết định** (chọn gì) →
**Hệ quả** (đánh đổi chấp nhận, phương án đã loại và vì sao).

Tiêu chí: quyết định mà 3 tháng sau ai đó (người hoặc AI) sẽ hỏi "tại sao lại làm thế này?".
Nếu quyết định bị đảo ngược, cập nhật file cũ ghi rõ "superseded" và trỏ sang quyết định mới.
