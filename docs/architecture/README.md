# architecture/

Tổng quan hệ thống mà không đọc ra được từ một repo đơn lẻ: các service/app liên quan
với nhau thế nào, ranh giới trách nhiệm, luồng dữ liệu chính, môi trường deploy.

Tiêu chí: kiến thức xuyên-repo hoặc ngữ cảnh nghiệp vụ. Chi tiết bên trong một repo
thì để CLAUDE.md của repo đó lo.

Sơ đồ dùng mermaid trong markdown khi cần.
