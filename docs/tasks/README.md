# tasks/

Việc dở dang hoặc kế hoạch dài hạn cần bàn giao giữa các session.

Cấu trúc nội dung: **Mục tiêu** → **Đã làm** → **Còn lại** (bước tiếp theo cụ thể,
đủ để session mới bắt tay làm ngay) → **Ràng buộc / quyết định đã chốt**.

Đây là folder duy nhất có nội dung "hết hạn" theo thiết kế: task xong thì XÓA file
(kiến thức rút ra được thì chuyển sang knowledge/decisions trước khi xóa) và cập nhật index.
